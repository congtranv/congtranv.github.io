Foldable Code Editor

Trình chỉnh sửa code và văn bản theo phong cách VS Code, tối ưu riêng cho điện thoại màn hình gập.

Giới thiệu ứng dụng

Foldable Code Editor là trình chỉnh sửa code và văn bản theo phong cách VS Code dành cho Android, tối ưu cho điện thoại màn hình gập với bố cục thích ứng màn hình ngoài/trong, bàn phím tùy chỉnh 6 hàng, hỗ trợ mở/lưu file cục bộ (SAF) và WebDAV.

Tính năng nổi bật

  • Tối ưu cho màn hình gập: Màn hình ngoài cố định hướng dọc dùng bàn phím hệ thống; màn hình trong chia đôi Trên/Dưới (Editor + Bàn phím tùy chỉnh bố cục Foldable HID), tự căn theo bản lề và ngăn gọi bàn phím hệ thống khi chạm vào editor.
  • Bàn phím tùy chỉnh 6 hàng & Phím tắt: Đầy đủ phím PC (Esc, F1–F12, mũi tên, Home/End/PgUp/PgDn), giữ/latch modifier (Shift/Ctrl/Alt) và các phím tắt Ctrl (Ctrl+S, Ctrl+Z/Y, Ctrl+C/X/V/A, Ctrl+F, Ctrl+N, Ctrl+W).
  • Trình chỉnh sửa kiểu VS Code & WebDAV: Đa tab (xác nhận trước khi đóng tab chưa lưu), highlight cú pháp đa ngôn ngữ, Undo/Redo, Tìm kiếm & Thay thế, mở/lưu thư mục cục bộ (SAF) và kết nối WebDAV.
  • Tùy chọn màu phím & Chống lưu ảnh OLED: Chuyển đổi màu phím HID/Black trên thanh trạng thái, tự động Pixel Shift (±2dp mỗi 45 giây) và Auto-Dim khi không thao tác.
